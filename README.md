# منصة الخطة الفصلية — ثانوية الحليلة الأولى

نسخة أولية تعمل كـ static web app وتناسب GitHub Pages.

الملفات:
- index.html
- style.css
- script.js

النشر:
1. أنشئي مستودع GitHub.
2. ارفعي الملفات الثلاثة إلى الفرع main.
3. من Settings > Pages اختاري النشر من الفرع main.
4. افتحي رابط الموقع الذي يظهره GitHub.

ملاحظة: البيانات في هذه النسخة تحفظ محليًا في متصفح المستخدم، مع تصدير واستعادة JSON.
